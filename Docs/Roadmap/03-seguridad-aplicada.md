# 3. Seguridad aplicada

Completa primero [Sistemas y redes](02-sistemas-redes.md).

## Conceptos

La autenticación multifactor combina factores de categorías distintas, como conocimiento y posesión. El mínimo privilegio reduce las acciones disponibles si una cuenta se compromete. Mantén un inventario de componentes y revisa qué parches son aplicables antes de priorizarlos por exposición e impacto.

El cifrado protege datos con una clave. Una función hash transforma datos en un resumen que permite comprobar cambios cuando existe una referencia confiable. Las copias de seguridad ayudan a recuperar datos, y su utilidad se verifica con una restauración de prueba. El registro de cambios ayuda a investigar quién hizo qué y cuándo.

## Práctica

Diseña una configuración para un equipo ficticio con tres perfiles de usuario. Registra cinco controles que cubran identidad, permisos, actualizaciones, copias de seguridad y registros. Para cada uno, identifica el riesgo, el responsable y la verificación. Prioriza los dos primeros y justifica la decisión.

**Criterio de salida:** entrega una tabla con cinco controles comprobables. Incluye una restauración de prueba y un caso de acceso denegado por mínimo privilegio.
