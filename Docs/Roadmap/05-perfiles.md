# 5. Perfiles profesionales

Completa primero [Detección y respuesta](04-deteccion.md). Elige un perfil según las vacantes que te interesan y el tipo de trabajo que disfrutas. Los títulos varían entre empresas.

| Perfil inicial | Trabajo habitual | Proyecto de portafolio |
| --- | --- | --- |
| Analista SOC | Revisar alertas, clasificar casos y documentar escaladas | Informe de triaje con un conjunto sintético de eventos, conclusiones y limitaciones |
| Seguridad de aplicaciones | Revisar código y configuración, priorizar hallazgos y verificar correcciones | Revisión de una aplicación propia ficticia con recomendaciones y pruebas de controles |
| Seguridad en nube | Revisar roles, permisos, configuración y registros | Diseñar una matriz de acceso ficticia y documentar cómo comprobar el mínimo privilegio |
| Gobierno, riesgo y cumplimiento | Inventariar activos, evaluar riesgos y revisar evidencias de controles | Registro de riesgos para una organización ficticia con responsables y controles verificables |


Si eliges el perfil de analista SOC, puedes usar el [proyecto final de triaje](proyectos/soc/README.md) como entrega.

**Criterio de salida:** completa un proyecto con un README que describa el objetivo, los datos ficticios, los pasos para reproducir la práctica, el resultado y las limitaciones.
