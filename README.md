# CiberSecurity

Ruta autodidacta en español para aprender ciberseguridad desde cero y preparar evidencias para postular a un primer empleo. Puedes leerla desde GitHub y hacer las primeras prácticas sin instalar herramientas especializadas.

1. Abre el [mapa de aprendizaje](Docs/Roadmap/README.md).
2. Si empiezas desde cero, comienza por [Fundamentos](Docs/Roadmap/01-fundamentos.md).
3. Registra tus entregas y prepara tu [portafolio para un puesto junior](Docs/Roadmap/06-empleo.md).

El [SRS](Docs/SRS.md) define los requisitos del roadmap. La [guía de desarrollo](Docs/desarrollo.md) y [AGENTS.md](AGENTS.md) orientan a quienes contribuyen. El analizador Python del repositorio se usa en el [laboratorio de registros](Docs/Roadmap/04-deteccion.md).
