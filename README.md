# CiberSecurity

Proyecto de aprendizaje y desarrollo de herramientas de ciberseguridad defensiva. La primera etapa define cómo colaborar con una IA y cómo validar los cambios antes de incorporar código.

- [AGENTS.md](AGENTS.md) reúne las instrucciones para los asistentes de IA que trabajen en el repositorio.
- [Guía de desarrollo](docs/desarrollo.md) detalla el flujo de trabajo, los criterios de revisión y la primera funcionalidad propuesta.

La elección del lenguaje y las herramientas de desarrollo queda pendiente hasta definir la primera implementación.
